
# FitTrack - Workout Log

## Project Description
FitTrack is a personal fitness tracking application built with Python and Streamlit. It allows users to record workouts, track daily steps, and monitor their fitness progress through an interactive dashboard.

## Features

- **Dashboard:** View total workouts, exercise minutes, calories burned, and miles completed.
- **Add Workout:** Record workout type, date, duration, distance in miles, calories burned, intensity, and additional workout details.
- **Workout History:** Review previous workouts, filter by exercise type, and download workout data as a CSV file.
- **Step Tracker:** Enter daily steps, set a personal step goal, monitor progress, and view weekly activity charts.

## Technologies Used

- Python
- Streamlit
- Pandas

## How to Run the Application

1. Install the required packages:
   pip install -r requirements.txt

2. Run the application:
   python3 -m streamlit run app.py

3. Open the local URL provided in the terminal.

## Purpose

The purpose of FitTrack is to provide a simple and organized way for users to track their fitness activities, monitor progress, and stay motivated to reach their health and fitness goals.
